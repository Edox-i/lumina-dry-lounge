# Lumina Dry Lounge

A concept landing page for **Lumina Dry Lounge** — a fictional premium, fully alcohol-free cocktail lounge set in Powiśle, Warsaw. The site explores how a luxury nightlife experience can be built around what's in the glass rather than what isn't: "Spirits, reimagined."

This project was built as a university web development assignment.

## Live Demo

https://edox-i.github.io/lumina-dry-lounge/

## About the Concept

Lumina is presented as a sober-curious lounge that borrows the craft, glassware, and ritual of fine cocktail bars — minus the alcohol and the next-morning regret. The brand voice is "luxury without liability."

The single-page site is organised into the following sections:

- **Concept** — the premise and headline stats (0% alcohol, 20 signature drinks, 48 seats by reservation).
- - **Menu** — twenty drinks across three philosophies: Reimagined Classics, Polish Botanicals, and Adaptogenic Mood Boosters.
  - - **Experience** — the lounge atmosphere and service approach.
    - - **Private Events** — tasting flights, half-room buyouts, and full lounge takeovers.
      - - **About / Our Story** — the narrative behind a dry lounge.
       
        - ## Tech Stack
       
        - - **HTML** — page structure (`index.html`)
          - - **CSS** — styling and layout (`styles.css`)
            - - **JavaScript / JSX** — interactive components (`app.jsx`, `tweaks-panel.jsx`)

                ## Getting Started

                Clone the repository and open `index.html` in your browser, or serve the folder with any static file server:

                ```bash
                git clone https://github.com/Edox-i/lumina-dry-lounge.git
                cd lumina-dry-lounge
                ```

                The site is also deployed automatically via GitHub Pages.

                ## Notes

                This is a student project and a fictional concept. The lounge, menu, address, and contact details are illustrative and not a real business.
